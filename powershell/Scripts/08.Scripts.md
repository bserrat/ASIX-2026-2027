# Scripts PowerShell

L'objectiu d'aquesta pràctica és integrar els conceptes treballats durant la introducció a PowerShell:

- variables;
- tipus de dades;
- arrays;
- pipeline;
- `Select-Object`;
- `Where-Object`;
- propietats dels objectes;
- `if`, `elseif`, `else` i `switch`;
- `foreach` i `ForEach-Object`;
- scripts `.ps1`.

> **Important:** abans d'incorporar una ordre al script, és recomanable provar-la directament a la consola de PowerShell.

# 1. Informació bàsica del sistema

Crea un script anomenat:

```
infoSistema.ps1
```

El script ha de mostrar:

- nom de l'equip;
- usuari actual;
- versió de PowerShell;
- data i hora actuals;
- directori actual.

La sortida ha de ser clara i llegible.

Per exemple:

```
===== INFORMACIÓ DEL SISTEMA =====

Equip: ...
Usuari: ...
PowerShell: ...
Data: ...
Directori actual: ...
```

1.  Adjunta el script final.

        Write-Output "===== INFORMACIÓ DEL SISTEMA ====="
        Write-Output "Equip: $env:COMPUTERNAME"
        Write-Output "Usuari: $env:USERNAME"
        Write-Output "PowerShell: $($PSVersionTable.PSVersion)"
        Write-Output "Data: $(Get-Date)"
        Write-Output "Directori actual: $(Get-Location)"

2.  Explica el procés que has seguit o operacions que has executat abans d'obtenir el script final.
    > 1. Buscar per internet comanda per posar data, hora i directori actual.
    > 2. He comprovat les variables del sistema.
    > 3. He provat Get-Date i Get-Location.
    > 4. He ajuntat les ordres en un script.

# 2. Estat dels serveis

Crea:

```
estatServeis.ps1
```

El script ha de:

1. obtenir tots els serveis del sistema;
2. comptar quants estan en execució;
3. comptar quants no estan en execució;
4. mostrar el total de serveis;
5. mostrar els resultats al final.

Exemple:

```
===== ESTAT DELS SERVEIS =====

Total: 230
Running: 95
Not running: 135
```

> Sript final:

        $stopped = 0

        foreach ($servei in $serveis) {
        if ($servei.Status -eq "Running") {
                $running++
        } else {
                $stopped++
        }
        }

        Write-Output "===== ESTAT DELS SERVEIS ====="
        Write-Output "Total: $($serveis.Count)"
        Write-Output "Running: $running"
        Write-Output "Not running: $stopped"

> Pasos que he seguit:

> 1. He provat Get-Service per obtenir tots els serveis.
> 2. He utilitzat foreach per recórrer els serveis.
> 3. He utilitzat if per comprovar si estan en execució.
> 4. He comptat els serveis i he mostrat els resultats.

# 3. Processos amb més consum de CPU

Crea:

```
topProcessos.ps1
```

El script ha de mostrar els **10 processos amb més consum de CPU**.

La sortida ha de mostrar únicament:

```
Name
Id
CPU
```

Després mostra també:

```
Nombre total de processos: ...
```

> Script Final:

        $processos = Get-Process

        $processos | Sort-Object CPU -Descending | Select-Object -First 10 Name, Id, CPU

        Write-Output "Nombre total de processos: $($processos.Count)"

> Pasos que he seguit:

> 1. He utilitzat Get-Process per obtenir els processos.
> 2. He ordenat els processos amb Sort-Object segons la CPU.
> 3. He utilitzat Select-Object per mostrar els 10 primers.
> 4. He mostrat el nombre total de processos.

# 4. Anàlisi de fitxers d'una carpeta

Crea:

```
analitzaCarpeta.ps1
```

El script ha de treballar amb la carpeta des d'on s'executa.

Ha de mostrar:

- nombre total d'elements;
- els cinc fitxers més grans;
- nom i mida d'aquests fitxers.

Investiga les propietats retornades per:

```
Get-ChildItem
```

i utilitza-les per construir el pipeline.

Tingues en compte que pots trobar tant fitxers com carpetes.

> Script Final:

        $elements = Get-ChildItem
        $fitxers = Get-ChildItem -File

        Write-Output "Total d'elements: $($elements.Count)"
        Write-Output "===== 5 FITXERS MÉS GRANS ====="

        $fitxers | Sort-Object Length -Descending | Select-Object -First 5 Name, Length

> Passos a seguir:

> 1. He utilitzat Get-ChildItem per obtenir els elements de la carpeta.
> 2. He utilitzat Get-ChildItem -File per obtenir només els fitxers.
> 3. He ordenat els fitxers per mida amb Sort-Object.
> 4. He mostrat els cinc fitxers més grans amb Select-Object.

# 5. Diagnosi bàsica del sistema

Crea:

```
diagnosi.ps1
```

Ha de mostrar almenys quatre apartats.

## Processos

Mostra els cinc processos amb més CPU.

Propietats:

```
Name
Id
CPU
```

## Serveis

Mostra:

```
Total de serveis
Serveis en execució
Serveis no executats
```

## Fitxers

Mostra els tres fitxers més grans de la carpeta actual.

Propietats:

```
Name
Length
```

## Estat final

Al final mostra un petit resum:

```
===== RESUM =====

Processos analitzats: ...
Serveis analitzats: ...
Fitxers analitzats: ...
```

Organitza el script perquè sigui fàcil de llegir.

Pots utilitzar comentaris per separar els diferents blocs:

```
# =====================
# PROCESSOS
# =====================
```

> Script Final:

        # PROCESSOS
        $processos = Get-Process
        $processos | Sort-Object CPU -Descending | Select-Object -First 5 Name, Id, CPU

        # SERVEIS
        $serveis = Get-Service
        $running = ($serveis | Where-Object Status -eq "Running").Count

        Write-Output "Total serveis: $($serveis.Count)"
        Write-Output "En execució: $running"
        Write-Output "No executats: $($serveis.Count - $running)"

        # FITXERS
        $fitxers = Get-ChildItem -File
        $fitxers | Sort-Object Length -Descending | Select-Object -First 3 Name, Length

        # RESUM
        Write-Output "Processos analitzats: $($processos.Count)"
        Write-Output "Serveis analitzats: $($serveis.Count)"
        Write-Output "Fitxers analitzats: $($fitxers.Count)"

> Passos a seguir:

> 1. He obtingut els processos amb Get-Process i he mostrat els cinc amb més CPU.
> 2. He utilitzat Get-Service i foreach per comptar els serveis.
> 3. He utilitzat Get-ChildItem -File per obtenir els fitxers.
> 4. He mostrat els tres fitxers més grans i he afegit un resum final.

# 6. Processos pare

Fes un script que per cada procés del sistema ens monstri:

- El nom i id del procés (entre = a l'exemple).
- El total de threads associats al procés
- L'identificador i el temps de processador de cada thread. Es pot donar la circumstància que aquesta última dada no estigui informada o el seu valor sigui 00:00:00.

Exemple de sortida

```text
============================== svchost (2772) ==============================

Total threads: 5

ID: 2776 CPU TIME: 00:00:00.0156250
ID: 2784 CPU TIME: 00:00:00
ID: 2788 CPU TIME: 00:00:00.1718750
ID: 2804 CPU TIME: 00:00:00
ID: 4864 CPU TIME: 00:00:00

============================== wininit (780) ==============================

Total threads: 1

ID: 784 CPU TIME:

============================== winlogon (852) ==============================

Total threads: 2

ID: 856 CPU TIME: 00:00:00.156250
ID: 1184 CPU TIME: 00:00:00.0156250

============================== wlms (1828) ==============================

Total threads: 2

ID: 2548 CPU TIME: 00:00:00.0156250
ID: 3092 CPU TIME: 00:00:00.0156250
```

> Script Final:

        $processos = Get-Process

        foreach ($proc in $processos) {
        Write-Output "============================== $($proc.Name) ($($proc.Id)) =============================="

        $threads = $proc.Threads
        Write-Output "Total threads: $($threads.Count)"

        foreach ($thread in $threads) {
                Write-Output "ID: $($thread.Id) CPU TIME: $($thread.TotalProcessorTime)"
        }

        Write-Output ""
        }

> Passos a seguir:

> 1. He utilitzat Get-Process per obtenir els processos.
> 2. He utilitzat foreach per recórrer cada procés.
> 3. He consultat els threads de cada procés.
> 4. He mostrat el nom, l'ID, el nombre de threads i el temps de processador.

# Requisits generals

Tots els scripts han de:

1. tenir extensió `.ps1`;
2. executar-se amb PowerShell 7;
3. utilitzar noms de variables descriptius;
4. tenir el codi correctament indentat;
5. incloure algun comentari quan sigui necessari;
6. evitar codi que no sigui necessari;
7. mostrar una sortida comprensible per a l'usuari.

Abans de donar un script per acabat:

```
prova cada part a la consola
        ↓
comprova el resultat
        ↓
incorpora-la al script
        ↓
executa el script complet
```
