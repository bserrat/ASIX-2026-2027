Port HTTPS

> if ($port -eq 443) {

> $port = 80

## 2. if o switch

Crea:

```
$estat = 2
```

Fes que el programa mostri:

```
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions.

> IF:

    if ($estat -eq 1) {
        Write-Output "Iniciant"
    } elseif ($estat -eq 2) {
    Write-Output "Executant"
    } elseif ($estat -eq 3) {
        Write-Output "Finalitzat"
    } elseif ($estat -eq 4) {
    Write-Output "En espera"
    } else {
    Write-Output "Estat desconegut"
    }

> Switch:

    switch ($estat) {
        1 { Write-Output "Iniciant" }
        2 { Write-Output "Executant" }
        3 { Write-Output "Finalitzat" }
        4 { Write-Output "En espera" }
        default { Write-Output "Estat desconegut" }
    }

> if permet comprovar diferents condicions, mentre que switch és més còmode quan tenim diferents valors possibles d'una mateixa variable.

## 4. Condicions combinades

Crea:

```powershell
$port = 443
$actiu = $true
```

Mostra:

```text
Servei disponible
```

només quan el port sigui el 443 i estigui actiu.

> Resposta:

    if ($port -eq 443 -and $actiu -eq $true) {
        Write-Output "Servei disponible"
    }

## 7. Objectes

Quants serveis en el teu sistema estan configurats amb el servei d'arrencada automàtic quan s'inicia l'equip?

Proposa diferents codis de resolució.

> Proposta 1:

    $n = 0
    foreach ($servei in Get-CimInstance Win32_Service) {
        if ($servei.StartMode -eq "Auto") {
            $n++
        }
    }
    $n

> Proposta 2:

    $n = 0
    Get-CimInstance Win32_Service | ForEach-Object {
        if ($_.StartMode -eq "Auto") {
            $n++
        }
    }
    $n

> Proposta 3:

    $s = @(Get-CimInstance Win32_Service)
    $i = 0
    $n = 0
    while ($i -lt $s.Count) {
        if ($s[$i].StartMode -eq "Auto") { $n++ }
        $i++
    }
    $n
